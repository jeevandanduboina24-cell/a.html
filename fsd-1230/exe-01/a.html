Working of Lists in HTML

1. Unordered List

An unordered list displays items with bullets.

  • Apple
  • Banana
  • Mango

2. Ordered List

An ordered list displays items with numbers.

  1. Wake up
  2. Have breakfast
  3. Go to school

3. Description List

A description list contains terms and their descriptions.
